Description
-----------
A rounded-square CJK sans. Every stroke corner and terminal uses one radius
(70/1000 em) as a true circular fillet (tangent-exact quadratic arcs), so the structure
reads square while the details stay soft.

Build 2.000 adds three variation axes built from eight masters that share a
single outline structure. For every glyph the contour count, point count,
point order and on/off flags are identical in all eight masters, which makes
interpolation safe across the whole design space.
